# ماموریت پرچم - پروژه کامل Android

این پروژه یک بازی دوبعدی پلتفرمر برای اندروید است و شامل:
- منوی اصلی و انتخاب منطقه
- ۳ منطقه
- بلاک‌های جامد با برخورد و ایستادن روی آن‌ها
- دشمن‌های متحرک
- سکه
- جان
- چک‌پوینت
- پرچم قرمز و پرچم سبز
- کنترل لمسی و کیبورد
- صفحه توقف بازی
- ظاهر اختصاصی و محیط چندلایه

## ساخت APK
پروژه را با Android Studio باز کنید و از مسیر:
Build > Build APK(s)
نسخه Debug را بسازید.

حداقل Android: 6.0 (API 23)
Target SDK: 35

این پروژه برای اجرای بازی از WebView داخلی اندروید استفاده می‌کند و به اینترنت نیاز ندارد.
