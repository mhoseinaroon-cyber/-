# 🎮 ماموریت پرچم | WarFlag

بازی دوبعدی پلتفرمر اندروید با کنترل لمسی؛ مأموریت بازیکن رسیدن به پرچم قرمز، پایین آوردن آن و بالا بردن پرچم سبز است.

## ویژگی‌ها
- منوی اصلی و انتخاب منطقه
- سه منطقهٔ بازی
- سکوها و بلوک‌های جامد با برخورد واقعی
- دشمن‌های متحرک، سکه‌ها و جان‌ها
- چک‌پوینت‌ها
- مأموریت پرچم قرمز و سبز
- کنترل لمسی و پشتیبانی از صفحه‌کلید
- مکث بازی و پس‌زمینهٔ چندلایه
- اجرای بازی به‌صورت آفلاین در WebView اندروید

## ساختار پروژه
- `app/src/main/assets/index.html`: منطق و ظاهر بازی
- `app/src/main/java/com/warflag/game/MainActivity.java`: فعالیت اندروید و WebView
- `app/src/main/AndroidManifest.xml`: تنظیمات برنامه
- `app/build.gradle`: تنظیمات ماژول اندروید

## ساخت APK
پروژه را در یک محیط سازگار با پروژه‌های Gradle اندروید، مانند AndroidIDE یا Android Studio، باز کنید و وظیفهٔ `assembleDebug` را اجرا کنید. فایل APK دیباگ معمولاً در این مسیر ساخته می‌شود:

`app/build/outputs/apk/debug/app-debug.apk`

تنظیمات فعلی پروژه:
- `minSdk`: 23 (Android 6.0)
- `compileSdk`: 35
- `targetSdk`: 35
- نسخهٔ برنامه: 1.0

**توجه:** این مخزن به‌عنوان سورس آمادهٔ انتشار در GitHub بسته‌بندی شده است؛ ساخت APK در این محیط تأیید نشده است. برای ساخت، باید SDK مربوط به API 35 و JDK 17 به‌همراه نسخهٔ سازگار Gradle/Android Gradle Plugin در دسترس باشد.

## بارگذاری در GitHub با گوشی
1. وارد GitHub شوید و یک مخزن جدید (New repository) بسازید.
2. نام پیشنهادی: `WarFlag`
3. فایل `WarFlag_GitHub_Ready.zip` را از حالت فشرده خارج کنید.
4. محتویات پوشهٔ `WarFlag_GitHub_Ready` را در صفحهٔ مخزن با گزینهٔ **Add file → Upload files** بارگذاری کنید. خود فایل ZIP را می‌توانید هم بارگذاری کنید، اما برای نمایش درست کدها بهتر است محتویات آن را بارگذاری کنید.
5. در پایین صفحه، **Commit changes** را بزنید.
